# Code map: every function, where it is, who calls it

Generated by `scripts/code_map.py` from the code itself (run it again after changes). 673 functions and classes in 48 files. In a terminal: `uv run python scripts/code_map.py who <function>`.

**Reading a line:** `line  name — what it does | called by: ... | calls: ...`. A `~` before a name means the function is passed as an argument (not called directly), e.g. `asyncio.to_thread(_load_context, ...)` or a LangGraph node registered in `build_agent_graph`. A `>` means control is handed over by a route (a `route_after_*` function sends the graph to the next node, `execute_tool` dispatches to a tool by name).

Cross-checked on 2026-10-16 against graphify's own graph of this project: it found 1,111 calls between functions of `app/`; this map finds 97% of them. The rest are calls into small helper functions defined *inside* another function (`run`, `load`, `work`), which this map counts as part of the function that contains them. Re-check any time with `scripts/code_map.py compare graph.json`.

## The spine: follow one message from start to finish

**1. Start: `uvicorn main:app` imports main.py**

- `main.py:1 <module>` 
- `app/firstrun.py:87 ensure_setup()` — Returns "ok" (already set up), "ran" (the wizard ran) or "skipped" (could not or should not ask).
- `app/config.py:17 Settings` — Application configuration for WalletLedger.
- `app/db.py:16 _build_engine()` — SQLite for local/single-user use, PostgreSQL for production; chosen by config.
- `app/bot/agent.py:1368 build_agent_graph()` — ingress -> planner -> guard (interrupt) -> executor -> planner|renderer, checkpointed.
- `main.py:26 lifespan()` 
- `app/db.py:143 init_db()` — Initializes tables in database.
- `app/services_ai/tool_client.py:69 start()` — Connect to the MCP server when TOOL_MODE=mcp. Returns the active mode.
- `app/bot/telegram.py:372 start()` — Start the bot(s) according to settings. Returns the mode: off, polling or webhook.

**2. A Telegram message arrives**

- `app/bot/telegram.py:289 on_text()` 
- `app/bot/main.py:158 handle_incoming()` — Single entry point for a text message from any channel: returns text plus optional buttons.
- `app/bot/onboarding.py:150 intercept()` — Called for every non-command message. A Reply if onboarding handled it, else None (carry on as usual).
- `app/bot/agent.py:1558 process_user_interaction_ex()` — Entry point for the Telegram bot: run (or resume) the graph and persist both messages.

**3. The LangGraph agent runs five nodes**

- `app/bot/agent.py:972 ingress_node()` — No LLM: key paste short-circuit, persona command, context + history, per-turn reset.
- `app/bot/agent.py:1020 planner_node()` — One LLM call: conversation + tool schema -> tool calls (to guard) or final text.
- `app/bot/agent.py:1135 guard_node()` — No LLM: pause with interrupt() when any proposed call needs the user's Yes.
- `app/bot/agent.py:1230 executor_node()` — No LLM: run the approved calls (user_id injected), one tool message per call.
- `app/bot/agent.py:1289 renderer_node()` — No LLM: planner text, else fixed templates; then the persona header and budget note.

**4. The executor reaches the database**

- `app/services_ai/tool_client.py:125 call_tool()` — Run one ledger tool and return its result dict. Raises on tool failure in both modes.
- `app/services_ai/mcp_server.py:677 execute_tool()` — Dispatch one registered agent tool and return a JSON-serializable result.
- `app/services_ai/mcp_server.py:58 log_expense()` — Record an expense and debit its payment account (``source``: chat, pdf, sms...).
- `app/services/ledger.py:238 record_transaction()` — Logs an expense or income and updates the corresponding account balance atomically.
- `app/services/ledger.py:19 _adjust_balance()` — Add `delta` to an account's balance inside the database, in one statement.

**5. The reply goes back**

- `app/bot/agent.py:1443 _outcome_from()` — Turn a graph run (finished or paused on a confirmation) into an Outcome.
- `app/bot/main.py:209 _reply_for()` — Text plus the right buttons: Yes/Cancel for a question, Undo for what was just recorded.
- `app/bot/telegram.py:165 deliver()` — Send a Reply as new message(s): photo / file / text, with its buttons.
